# 🚀 Subhendu Hembram — Developer Portfolio

A modern full-stack developer portfolio built with React, Three.js, GSAP, Framer Motion, Firebase, and a custom secure admin dashboard. Designed to showcase projects, skills, certifications, and professional.

Live updates, dynamic content management, resume generation, OTP-based authentication, and cloud-hosted media management are integrated into a production-ready architecture.

## ⚙️ Local Development

### Prerequisites

* Node.js 18+
* npm

### Clone Repository

```bash
git clone https://github.com/subhenduprasad/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file:

```env
VITE_SERVER_BASE_URL=http://localhost:5001
```

### Start Development Server

```bash
npm run dev
```

Application will run on:

```text
http://localhost:5173
```

---

## 🚀 Production Build

Build the application:

```bash
npm run build
```

Preview build:

```bash
npm run preview
```

Generated files will be available inside:

```text
dist/
```
